# Extract metadata from jax_fit object

Internal S3 method. Extracts metadata from a jax_fit object, compatible
with cmdstanr's metadata() method.

## Usage

``` r
# S3 method for class 'jax_fit'
metadata(x)
```

## Arguments

- x:

  A jax_fit object.

## Value

A list containing metadata.

## Examples

``` r
TRUE
#> [1] TRUE
```
