# coevolve: Fit Bayesian Generalized Dynamic Phylogenetic Models using 'Stan' or 'JAX'

Fit Bayesian generalized dynamic phylogenetic models using 'Stan' or
'JAX'. The package allows an arbitrary number of variables with
different response distributions to coevolve on a phylogenetic tree via
an Ornstein-Uhlenbeck evolutionary process, allowing users to assess
directionality between coevolving variables. The optional JAX backend
enables high-performance sampling with NumPyro and potential GPU
acceleration via 'reticulate'.
